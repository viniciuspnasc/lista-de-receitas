# 🍳 Lista de Receitas

Aplicação desenvolvida no **Construct 3** como projeto de estudo, com foco em lógica de programação, criação de interfaces e gerenciamento de informações.

O projeto permite organizar receitas por meio de uma interface interativa, possibilitando criar, selecionar, visualizar, excluir e salvar informações.

## 📌 Sobre o projeto

O objetivo do projeto foi desenvolver uma aplicação simples para gerenciamento de receitas, trabalhando conceitos de interface, eventos e armazenamento de informações dentro do Construct 3.

O projeto possui diferentes telas para organizar o fluxo da aplicação, incluindo carregamento, listagem e visualização das receitas.

## ⚙️ Funcionalidades

- 📋 Listagem de receitas
- ➕ Criação de novas receitas
- 🔎 Seleção de receitas
- 👁️ Visualização das informações da receita
- 🗑️ Exclusão de receitas
- 💾 Salvamento de informações
- 📱 Interação por toque
- 🔄 Navegação entre diferentes telas

## 🧠 Conceitos trabalhados

## 📂 Estrutura do projeto

O projeto foi organizado em diferentes layouts e folhas de eventos, incluindo:

- `Loading` — tela de carregamento
- `Listas` — gerenciamento/listagem das receitas
- `Receitas` — visualização e interação com as receitas

## 🎯 Objetivo de aprendizado

Este projeto fez parte da minha formação prática em desenvolvimento e foi utilizado para trabalhar conceitos fundamentais de programação e desenvolvimento de aplicações interativas.

Durante o desenvolvimento, pratiquei principalmente a organização de dados, criação de eventos, interação com elementos da interface e construção do fluxo de uma aplicação.
